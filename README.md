## Project Description

CommunityHub is a full-stack community platform built as part of the IYF Weekend Academy Season 11 Week 12 project. The application allows users to register, log in, and interact with community posts. The React frontend communicates with a Node.js and Express backend, while MongoDB is used to store application data. The project was built to practice full-stack development, REST API integration, authentication, database management, and deployment.
