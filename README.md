## Project Description

CommunityHub is a full-stack community site that I developed. The site allows users to sign up, log in, and interact with community posts. The React frontend communicates with a Node.js and Express.js backend, while MongoDB is used to store the application data. The project was built to practice full-stack development, REST API integration, authentication, database management, and deployment.

- User login
- JWT authentication
- Protected routes
- View all community posts

- Create posts
- Edit posts
- Delete posts
- Loading states
- User-friendly error handling
- Responsive design
- REST API integration
- MongoDB database persistence
- Backend health check endpoint

## Lessons Learned

- How to connect a React frontend to a Node.js and Express.js backend.
- Use MongoDB and Mongoose to store and manage application data.
- How to configure CORS and environment variables.
- How to deploy the backend and frontend.

## Challenges Faced

- Deploying the backend.
- Environment variable errors e.g MONGODB_URI and JWT_SECRET.
- MongoDB connection string and database credentials issues.
- CORS errors.
